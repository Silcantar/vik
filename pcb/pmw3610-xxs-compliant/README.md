# VIK-Compliant PMW3610 Trackball PCB - XXS Version

## Overview

This is a slightly modified version of ykz89's PMW3610-xxs module. The MOTION
pin of the sensor is moved from the VIK MOSI pin to GP2 to make the module
compliant with the VIK standard.

## Fabrication and BOM

For PCB fabrication, you can use the files in the jlcpcb/production_files folder.

* `pmw3610-xxs-compliant.zip` - the file used to fabricate the pcb
* `bom.csv` - used for PCBA. You can also use the part numbers in this file to look up the exact parts as [lcsc.com](https://lcsc.com)
* `positions.csv` - used for PCBA

Using the 3 files above, this has been tested at [jlcpcb.com](https://jlcpcb.com)
These files were generated by the [KiCAD JLCPCB tools plugin](https://github.com/Bouni/kicad-jlcpcb-tools).
